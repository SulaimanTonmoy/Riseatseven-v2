# Rise at Seven Website Replica

A modern, responsive replica of the Rise at Seven website built with vanilla HTML, CSS, and JavaScript. This project recreates the design and functionality of the award-winning search-first content marketing agency's website.

## 🚀 Features

- **Modern Design**: Clean, professional layout matching Rise at Seven's aesthetic
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Navigation**: Dropdown menus with hover and click support
- **Smooth Animations**: Scroll-triggered animations and micro-interactions
- **Portfolio Section**: Dynamic work showcase with hover effects
- **Services Grid**: Comprehensive service offerings display
- **Mobile Menu**: Hamburger menu for mobile devices
- **Performance Optimized**: Lazy loading, debounced events, and efficient animations

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and SEO
- **CSS3**: Modern CSS with Grid, Flexbox, and custom animations
- **Vanilla JavaScript**: No frameworks, pure JavaScript for maximum performance
- **Google Fonts**: Inter font family for modern typography
- **Font Awesome**: Icon library for UI elements

## 🔧 Customization

### Colors
Edit the CSS variables at the top of `styles.css`:

```css
:root {
    --primary-color: #000;
    --secondary-color: #fff;
    --accent-color: #667eea;
    --background-color: #f8f8f8;
}
```

### Fonts
Update the Google Fonts import in `index.html`:

```html
<link href="https://fonts.googleapis.com/css2?family=Your+Font:wght@300;400;500;600;700;800;900&display=swap" rel="stylesheet">
```

### Content
All text content is easily editable in the HTML file. Images and logos can be replaced in the `assets/` folder.
